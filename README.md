# نمونهٔ سکشن اسکرولی آکس چوب

اتاق خام، و با اسکرول کابینت‌های پروژهٔ AUX501 یکی‌یکی سر جایشان می‌نشینند.

- در HTML صفحه فقط حدود ۱ کیلوبایت است (بین نشانه‌های `AKX:START` و `AKX:END` در `index.html`) و به هیچ کتابخانه‌ای نیاز ندارد.
- `akx.js` و تصویرها فقط وقتی لود می‌شوند که بازدیدکننده حدود یک صفحه با سکشن فاصله داشته باشد.
- حرکت فقط با `transform` و `opacity` است، پس چیدمان صفحه دوباره محاسبه نمی‌شود.
- برای کاربران با `prefers-reduced-motion` یا حالت کم‌مصرف، فقط تصویر نهایی نشان داده می‌شود.
- اگر تصویری لود نشود، سکشن کنار می‌رود و صفحه به‌هم نمی‌ریزد.

برای استفاده روی سایت، `akx.js` و `img/` را آپلود کنید و مسیر اسکریپت و `data-base` را تغییر دهید.

`source/` شامل فایل‌های اصلی است و در گیت نیست. `tools/build-assets.py` تصویرهای وب را از آن می‌سازد.

عکس نهایی از پروژهٔ واقعی AUX501 است. اتاق خام و بخش‌های پشت جزیره با هوش مصنوعی ساخته شده‌اند.

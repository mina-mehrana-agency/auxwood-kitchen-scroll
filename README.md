# نمونهٔ سکشن اسکرولی آکس چوب

نقشهٔ معماری آشپزخانه به سبک بخش «How we work» سایت Home Fresh Air. موقع ورود سکشن، طرح مدادی و اتاق خام کشیده می‌شوند. بعد با اسکرول کابینت‌ها سر جایشان می‌نشینند، برگهٔ نقشه کامل می‌شود، رنگ می‌آید و در آخر نور و آدم‌ها.

- بدون هیچ عکس و کتابخانه‌ای است. همهٔ نقشه SVG داخل `akx.js` است (حدود ۱۴ کیلوبایت فشرده).
- در HTML صفحه کمتر از ۱ کیلوبایت است (بین نشانه‌های `AKX:START` و `AKX:END` در `index.html`).
- `akx.js` فقط وقتی لود می‌شود که بازدیدکننده حدود یک صفحه با سکشن فاصله داشته باشد. اگر لود نشود، سکشن کنار می‌رود.
- برای کاربران با `prefers-reduced-motion` یا حالت کم‌مصرف، فقط نقشهٔ کامل بدون حرکت نشان داده می‌شود.

برای استفاده روی سایت، `akx.js` را آپلود کنید و مسیر اسکریپت را در HTML تغییر دهید.

نقشه از اندازه‌های حدودی و به‌صورت سه‌بعدی در `tools/build-scene.js` ساخته می‌شود و `akx.js` را از روی `tools/akx.template.js` می‌نویسد:

```bash
node tools/build-scene.js
```

این نقشه بازطراحی آزادی از پروژهٔ AUX501 است، نه نقشهٔ اجرایی آن.

نمونهٔ قبلی که با عکس ساخته شده بود در تگ `photo-version` مانده است.

# نمونهٔ سکشن اسکرولی آکس چوب

یک آشپزخانهٔ سه‌بعدی واقعی که در Blender مدل و رندر شده است. سکشن با اتاق خام شروع می‌شود و با اسکرول، کابینت‌ها، هود، یخچال، کافی‌بار با شلف‌ها، جزیره با سینک و وسایل یکی‌یکی سر جایشان می‌نشینند. در آخر اتاق کامل دیده می‌شود.

- در HTML صفحه کمتر از ۱ کیلوبایت است (بین نشانه‌های `AKX:START` و `AKX:END` در `index.html`) و به هیچ کتابخانه‌ای نیاز ندارد.
- `akx.js` و تصویرها فقط وقتی لود می‌شوند که بازدیدکننده حدود یک صفحه با سکشن فاصله داشته باشد.
- حرکت فقط با `transform` و `opacity` است و موتور سه‌بعدی داخل مرورگر اجرا نمی‌شود.
- برای کاربران با `prefers-reduced-motion` یا حالت کم‌مصرف، فقط تصویر نهایی بدون حرکت نشان داده می‌شود.
- اگر فایلی لود نشود، سکشن کنار می‌رود و صفحه به‌هم نمی‌ریزد.

برای استفاده روی سایت، `akx.js` و `img/` را آپلود کنید و مسیر اسکریپت و `data-base` را تغییر دهید.

## ساخت دوباره

مدل در `tools/render/scene.py` است. رندر روی GitHub Actions با workflow به نام `render` اجرا می‌شود. بعد از دانلود خروجی، این دستور تصویرهای وب و `akx.js` را می‌سازد:

```bash
python tools/build.py <پوشهٔ رندرها>
```

این یک آشپزخانهٔ خیالی است، نه پروژهٔ واقعی آکس چوب.

نسخه‌های قبلی در گیت مانده‌اند: نمونهٔ عکسی در تگ `photo-version` و نمونهٔ نقشه‌ای در تگ `drawing-version`.
